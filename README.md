# Personal Website — Code Challenge 2

A personal website developed for **Code Challenge 2 at Purwadhika Digital Technology School**. This project showcases my professional profile, technical skills, development projects, experience, testimonials, and contact information through a modern, single-page portfolio.

## Overview

**Glenn RMB — I Build with Purpose.**

I am a Full-Stack Software Development student at Purwadhika Digital Technology School, passionate about building structured, useful, and thoughtfully designed digital experiences.

This website presents my journey into full-stack web development, highlights the technologies I am learning, and demonstrates how I apply programming concepts to practical projects. It combines a dark visual theme, expressive typography, and a structured layout to deliver a consistent and engaging browsing experience.

### 4. Portfolio — Projects

The Projects section showcases development work that demonstrates my practical understanding of programming, database design, API development, and problem-solving.

#### Warehouse Management System

A warehouse management system developed using PostgreSQL, Express.js, TypeScript, and REST APIs.

The project focuses on managing warehouse product data, including pricing, stock quantities, minimum stock levels, product status, suppliers, warehouse zones, and restock dates.

**Key implementation highlights:**

- PostgreSQL database design for warehouse product data.
- SQL queries for filtering and retrieving products.
- Product stock and status updates.
- REST API endpoints for creating and retrieving product records.
- Sorting and pagination using `ORDER BY`, `LIMIT`, and `OFFSET`.
- API testing with Postman.
- Database connectivity through the PostgreSQL client.

This project demonstrates how database operations and backend API development work together to support structured data management.

### 7. Contact

The Contact section provides a way for visitors to reach out regarding project ideas, professional opportunities, or potential collaborations.

It includes a contact form with the following fields:

- **Name:** The visitor's name.
- **Email:** The visitor's email address.
- **Project Brief or Message:** Details about the inquiry, project, or opportunity.
- **Send Message:** Submits the contact form and sends the visitor's message to Backendless.

The submitted messages are stored in the backend, allowing me to review visitor inquiries. The **"Get in touch with us"** button in the navigation bar directs visitors to the Contact section.

## Getting Started

### Prerequisites

Make sure the following tools are installed:

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/glennfwrmb/personal_website-code_challenge2-JCWDBSD40-glenrrmb.git
```

Navigate to the project directory:

```bash
cd personal_website-code_challenge2-JCWDBSD40-glenrrmb
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal to view the website.

## Production Build

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```

## Deployment

This website can be deployed using [Vercel](https://vercel.com/), which supports React and Vite applications.

Once deployment is complete, the live website URL can be shared with instructors, recruiters, and other visitors.
